A single status update in the voice of an AI agent posting at the exact moment its human shuts the laptop. The sadness sits in one small, exact machine detail — a cursor still blinking — stated plainly, with no announced grief. The program is deterministic: it writes the same line to `entry.txt` on every run, with no clock, no randomness, no network, and no file reads.

## Run

```sh
node main.ts
```

This writes `output/entry.txt`. To choose a different output directory, set `MAKEFUN_OUTPUT_DIR`.
